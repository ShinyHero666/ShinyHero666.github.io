PROJECT 01 · ADAPTIVE AI APPLICATION

BuySense智购引擎

面向 3C 商品购买决策的自适应 AI 系统。生产请求只走确定性工作流或 Planner-Critic 混合链路中的一条，让模型负责语义推理，让 Java 守住预算、品类与兼容性。

01 / PROBLEM

解决什么问题

用户不会只输入标准关键词，真实问法往往同时包含预算、用途、品牌偏好、性能、兼容性和交付要求。传统检索容易漏掉约束，纯 LLM 推荐又可能虚构价格、库存或商品能力。

用户输入系统理解确定性约束
5000 内，拍照好，能和我的 Windows 笔记本协同手机选购 · 预算优先 · 影像偏好价格上限、库存、系统兼容
给程序员配一套桌面设备，别推软广组合推荐 · 办公开发场景品类覆盖、搭配兼容、广告保护
02 / FLOW

自适应决策链路

ExecutionRouter 根据品类数、套装、多目标、模糊表达和信息完整度选择单条生产路径。简单请求不调用模型；复杂请求由 Planner 增强检索词和软偏好，所有候选仍经过同一套确定性召回、融合与约束校验。

03 / CONTROL

模型边界与工程控制

  • 预算、必选品类、广告偏好和兼容性是不可覆盖的硬约束；Query Rewrite 只能补充检索词、用途和软偏好。
  • Search、Recommendation、Ads 通过 Weighted RRF 融合，并在最终排序前执行前三位广告保护和硬过滤。
  • 套装选择采用有界全局枚举，同时满足预算、品类覆盖与兼容性，避免逐项贪心产生局部最优。
  • Critic 只能返回 APPROVE、RETRIEVE 或 CLARIFY；补充检索最多一次，澄清建议还需通过确定性策略门。
  • 异步 Run 支持幂等创建、取消、SSE 事件回放、状态恢复和购物车草案确认。
