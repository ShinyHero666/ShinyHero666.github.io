PROJECT 01 · BOUNDED DECISION AGENT

BuySense智购决策 Agent

面向 3C 数码与户外露营场景的智能购买决策平台。所有请求执行同一条有界协作链：LLM 负责补充软偏好和受约束的检索意图，Java 服务负责预算、品类、库存、兼容性、广告与交易边界。

01 / PROBLEM

解决什么问题

用户不会只输入标准关键词，真实问法往往同时包含预算、用途、品牌偏好、性能、兼容性和交付要求。传统检索容易漏掉约束，纯 LLM 推荐又可能虚构价格、库存或商品能力。

用户输入系统理解确定性约束
5000 内，拍照好，能和我的 Windows 笔记本协同手机选购 · 预算优先 · 影像偏好价格上限、库存、系统兼容
给程序员配一套桌面设备，别推软广组合推荐 · 办公开发场景品类覆盖、搭配兼容、广告策略
02 / FLOW

有界协作链路

系统不再为请求设计容易误判的快慢路由。Intent Router 先解析显式约束并提出检索意图；Search 与 Ads 并行召回，Recommendation 基于搜索证据扩展候选；随后完成融合、组合求解、证据刷新、确定性审核和一次有界 Critic 修订。

意图解析显式约束 / 检索意图 / Domain Pack
多路召回Search + Ads 并行 / Recommendation 扩展
融合与组合Weighted RRF / 兼容图枚举
证据刷新价格 / 库存 / 评论切面
审核与输出确定性 Audit / Critic / Lead
03 / CONTROL

模型边界与工程控制

  • Domain Pack 隔离目录、同义词、兼容图、评论切面与业务策略；当前以 3C 为主场景，并用户外露营验证领域扩展边界。
  • LLM 只能补充检索词、软偏好和既有 SKU 排序建议，不能覆盖预算、必选品类、库存、兼容性或广告策略。
  • Search 与 Recommendation 使用 Weighted RRF 融合；Ads 走独立的相关性、质量、疲劳度、披露和展示位门禁。
  • 兼容图在预算内枚举可行套装，同时满足品类覆盖和搭配约束，避免逐项贪心产生局部最优。
  • Retail Provider SPI 解耦本地快照、HTTP 数据源和只读 Shopify GraphQL；确认前刷新价格与库存，远端故障快照不能直接确认。
  • 异步 Run 采用数据库原子准入、有界执行器、租约续期和 fencing，支持取消、幂等复用、SSE 回放与过期任务恢复。
  • 确定性 Audit 先于 Critic 执行，最多允许一次补充检索；最终只生成 paymentAuthorized=false 的购物车草案，不创建订单或发起支付。
