PROJECT 01 · AGENT APPLICATION

BuySense智购引擎

面向 3C 商品购买决策的多 Agent 搜广推系统。把模糊需求转成可执行约束，并让模型规划与确定性算法在同一条证据链上协作。

01 / PROBLEM

解决什么问题

用户不会只输入标准关键词，真实问法往往同时包含预算、用途、品牌偏好、性能、兼容性和交付要求。传统检索容易漏掉约束，纯 LLM 推荐又可能虚构价格、库存或商品能力。

用户输入系统理解确定性约束
5000 内，拍照好，能和我的 Windows 笔记本协同手机选购 · 预算优先 · 影像偏好价格上限、库存、系统兼容
给程序员配一套桌面设备，别推软广组合推荐 · 办公开发场景品类覆盖、搭配兼容、广告保护
02 / FLOW

决策链路

主控 Agent 维护任务边界和预算，角色 Agent 只在自己的职责范围内提出候选与证据。商品价格、库存、兼容性和广告规则由工具服务校验，避免模型直接决定事实。

Query 理解实体、预算、偏好、硬约束
多路召回关键词、语义、规则与个性化
Agent 协作搜索、推荐、广告、质检
确定性精排RRF、兼容性、价格、库存
证据输出推荐理由、风险与备选方案
03 / CONTROL

Agent 如何受控

  • 固定六类角色：Intent、Search、Recommendation、Ads、Critic、Lead，避免角色无限扩张。
  • 单次运行限制任务数、模型调用数与复议次数，超限后走确定性降级路径。
  • 异步 Run + SSE 返回事件流，支持取消、幂等提交和失败恢复。
  • Critic 只检查证据完整性、约束冲突与广告干扰，不负责重新生成全部结果。
