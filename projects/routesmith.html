PROJECT 02 · AI INFRASTRUCTURE

RouteSmith智路网关

面向 Agent 应用的统一模型入口。屏蔽不同模型协议与供应商差异，将路由、故障转移、配额、预算和审计集中到可操作的治理控制面。

01 / PROBLEM

为什么需要网关

当多个 Agent 直接接入不同模型服务时，协议适配、凭证、重试和成本逻辑会散落在业务代码中。模型切换会扩大改动范围，也难以统一追踪一次请求经过了哪个模型、花费多少、为何降级。

问题RouteSmith 的处理
OpenAI / Anthropic 请求格式不同协议适配层统一消息、流式事件与 Tool Use
上游限流或服务异常健康检查、冷却、重试和候选模型故障转移
团队成本难以控制Scoped API Key、团队配额、预算预留与结算
02 / FLOW

请求治理链路

业务侧只依赖兼容协议，网关根据调用身份、模型别名、健康状态和预算策略选择上游。每次尝试、降级与结算都进入统一请求台账。

兼容入口OpenAI / Anthropic API
身份与预算API Key、团队、配额
智能路由健康、冷却、策略与成本
Provider Adapter协议转换、流式与工具调用
审计结算请求台账、用量与告警
03 / RELIABILITY

可靠性设计

  • 将客户端 API Key 与上游供应商凭证隔离，避免业务应用直接持有模型密钥。
  • 通过健康状态和冷却窗口阻止持续请求故障节点，按候选顺序完成故障转移。
  • 预算采用预留、提交与释放流程，减少并发请求下的超额消费。
  • 流式响应保留生命周期事件，异常中断也能形成可追踪的请求记录。
04 / OPERATIONS

治理控制面

React 控制台提供模型与供应商状态、API Key、用户团队、配额预算、请求日志和治理策略视图；Prometheus 暴露运行指标，便于对接现有监控告警体系。

技术实现
